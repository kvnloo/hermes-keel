# Resources

## Hermes Keel

- [Hermes Keel repository](https://github.com/kvnloo/hermes-keel): specification, machine-readable level record, verifier, and evidence.
- [Level 0 report](https://github.com/kvnloo/hermes-keel/blob/main/evidence/level-0/t_c8dc8afb/report.md): human-readable proof narrative and limitations.
- [Level 0 manifest](https://github.com/kvnloo/hermes-keel/blob/main/evidence/level-0/t_c8dc8afb/manifest.json): task, run, worker, capability, nonce, and scope bindings.
- [Level 0 verifier](https://github.com/kvnloo/hermes-keel/blob/main/verify_level0.py): deterministic packet integrity checks.

## Execution system

- [Hermes Agent](https://github.com/NousResearch/hermes-agent): the runtime that owns messaging, tools, sessions, workers, and Kanban execution.
- [Hermes Agent documentation](https://hermes-agent.nousresearch.com/docs): official installation, configuration, and feature documentation.
- [Hermes Kanban documentation](https://hermes-agent.nousresearch.com/docs/user-guide/features/kanban): canonical tasks, runs, dispatch, review, and durable lifecycle behavior.

## Optional complementary systems

- [Firstmate](https://github.com/kunchenguid/firstmate): an optional subordinate supervisor and execution backend for already authorized work. It is not required or authorized at Level 0.
- [PM](https://github.com/kvnloo/_pm): a public intent and management system that may supply product and portfolio context without owning execution truth.
